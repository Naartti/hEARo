[LICENSE-APACHE](LICENSE-APACHE)). This file lists what it builds on.

## Rust dependencies

All Rust dependencies are permissively licensed — MIT, Apache-2.0 (incl. the LLVM exception),
BSD, ISC, Zlib, Unicode-3.0 or Unlicense, almost all dual MIT OR Apache-2.0 — with the single
exception below. The policy is enforced by `cargo deny check` (see `deny.toml`, run by
`just ci`). A full generated list will be bundled with the release app (M9); until then
`cargo deny list` prints it.

[ADR 0013](docs/adr/0013-uniffi-mpl-license-exception.md).

## Swift and Python

The Swift app uses only Apple system frameworks — no third-party Swift packages. The Python
project in `ml/` currently has development-only dependencies (pytest, ruff; both MIT), which
are not distributed.

## Copied or adapted code

No third-party source code has been copied into this repository. The permission check in
`crates/hearo-engine/src/ca/permission.rs` follows the same approach as AudioCap
(BSD-2-Clause) but is an independent implementation; if code from AudioCap is ever adapted,
its notice goes here.
